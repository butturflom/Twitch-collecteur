## 1. Vue d'Ensemble du Projet <a name="vue-densemble"></a>

### Objectif Principal
Développer un outil d'analyse avancée des données Twitch capable de produire des insights stratégiques vendables pour agences et streamers professionnels.

### Situation Actuelle
- Volume actuel : 100 streamers suivis
- Collecte : Données en live depuis 3 jours (prototype fonctionnel)
- Infrastructure : Ordinateur personnel (capacités RAM non définies)
- Base de données : Supabase (limites à évaluer)

## 4. Analyses de Bases <a name="analyses-bases"></a>

### 4.1 Métriques de Performance des Streamers

#### Indicateurs de Audience
- **Viewers en Direct** : Nombre moyen de spectateurs en temps réel
- **Peak Viewers** : Nombre maximum de spectateurs atteint
- **Heures de Stream** : Durée totale en heures de diffusion
- **Jours de Stream** : Nombre de jours diffusés

#### Calculs Clés
- **Taux de Disponibilité** = (Heures de Stream / Jours * 24) * 100
- **Taux de Croissance des Viewers** = ((Viewers actux - Viewers précédent) / Viewers précédent) * 100
- **Moyenne Quotidienne** = Total Viewers / Nombre de jours

### 4.2 Analyse de la Communauté des Chaînes

#### Métriques d'Engagement
- **Taux d'Interaction** = (Messages Chat / Viewers Moyens) * 100
- **Participation aux Shouts** = Nombre de fois où les viewers mentionnent la chaîne
- **Redemptions** = Nombre de redemptions d'émotes/subscriptions
- **Bits Cheered** = Montant total des bits utilisés

## 5. Analyses Comportementales <a name="analyses-comportementales"></a>

### 5.1 Migration des Viewers

#### Concept Clé
La migration décrit les déplacements des spectateurs d'une chaîne à une autre, révélant les préférences émergentes.

#### Types de Migrations Identifiées
- **Migration de Sécurité** : Spectateurs qui quittent une chaîne pour une plus connue
- **Migration de Découverte** : Nouveaux viewers trouvant des chaînes via d'autres streams
- **Migration de Niche** : Spectateurs déplaçant leur attention vers des contenus spécifiques

#### Indicateurs de Migration
- **Taux de Rotation** = (Nouveaux viewers / Viewers moyens) * 100
- **Index de Préférence** = (Viewers chaîne A vers chaîne B / Viewers chaîne B vers chaîne A)
- **Score de Migration** = Nombre de viewers uniques qui ont vu 2+ chaînes adjacentes

### 5.2 Analyse des Patterns Temporels
- Cycles diurnes/nocturnes
- Tendances saisonnières
- Prévisions comportementales

### 5.3 Analyse des Comportements Émergents
- Détection de tendances
- Algorithme de détection de breaking news
- Analyse de la chaîne d'acquisition des spectateurs

def calculer_top_streamers(periode='jour'):
    query = f"""
    SELECT s.nom, AVG(v.viewers_count) as viewers_moyen,
           SUM(s.heures_stream) as heures_totales
    FROM streamers s
    JOIN viewers_data v ON s.id_twitch = v.id_streamer
    WHERE v.timestamp >= NOW() - INTERVAL '{periode}'
    GROUP BY s.id_twitch, s.nom
    ORDER BY viewers_moyen DESC
    LIMIT 10
    """
    return execute_query(query)
Module Communautés Investies

def calculer_communautes_investies():
    query = """
    SELECT s.nom, 
           AVG(c.taux_interaction) as engagement_moyen,
           SUM(c.redemptions) as total_redemptions
    FROM streamers s
    JOIN community_metrics c ON s.id_twitch = c.id_streamer
    WHERE c.date >= CURRENT_DATE - 30  -- 30 derniers jours
    GROUP BY s.id_twitch, s.nom
    HAVING COUNT(c.date) >= 20
    ORDER BY engagement_moyen DESC
    LIMIT 10
    """
    return execute_query(query)
